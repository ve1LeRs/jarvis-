# J.A.R.V.I.S. — голосовой ассистент

Голосовой помощник в духе JARVIS из «Железного человека»: слушает wake word **«Джарвис»**, выполняет команды на русском и отвечает голосом.

## Возможности

| Команда | Что делает |
|--------|------------|
| «Джарвис, найди информацию о сосновом брусе» | Открывает Chrome и ищет в Google |
| «Джарвис, открой проводник» | Открывает Проводник Windows |
| «Джарвис, открой хром» | Запускает Google Chrome |
| «Джарвис, открой ютуб» | Открывает YouTube |
| «Джарвис, открой загрузки» | Папка Downloads |
| «Джарвис, который час» | Говорит текущее время |
| «Джарвис, заблокируй» | Блокирует компьютер |
| «Джарвис, помощь» | Список возможностей |

## Требования

- Windows 10/11 (также работает на macOS/Linux с адаптацией файлового менеджера)
- Python 3.10+
- Микрофон и динамики
- Google Chrome (желательно)
- Интернет (распознавание речи Google + голос Edge TTS)

## Установка

```bat
cd путь\к\проекту
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### PyAudio на Windows

Если `pip install PyAudio` падает, поставьте готовое колесо:

```bat
pip install pipwin
pipwin install pyaudio
```

или скачайте `.whl` с [ci.appveyor.com/project/intxcc/pyaudio](https://github.com/intxcc/pyaudio) под вашу версию Python.

Разрешите приложению доступ к микрофону в параметрах Windows.

## Автозапуск вместе с Windows

Чтобы JARVIS был «программой на ПК» и поднимался сам после включения:

1. Сначала один раз поставьте зависимости: `install_windows.bat`
2. Включите автозапуск: **`enable_autostart.bat`**
3. Перезайдите в Windows или перезагрузите ПК

Что происходит:
- в папку автозагрузки Windows кладётся скрипт `JARVIS_autostart.vbs`
- при входе в систему JARVIS стартует **без чёрного окна консоли**
- работает в фоне, иконка в системном трее (возле часов)
- ПК говорит приветствие и ждёт «Джарвис…»

Отключить автозапуск: `disable_autostart.bat`  
или голосом: *«Джарвис, убери из автозапуска»* / *«Джарвис, включи автозапуск»*

Проверка без перезагрузки — тихий запуск как при автостарте:

```bat
start_jarvis_silent.vbs
```

### Альтернатива вручную

1. `Win + R` → `shell:startup` → Enter  
2. Скопируйте туда `start_jarvis_silent.vbs` из папки проекта  

Или: Параметры Windows → Приложения → Автозагрузка — после `enable_autostart.bat` там может появиться запись.

## Запуск

```bat
start_jarvis.bat
```

или:

```bat
python -m jarvis
```

Режимы:

```bat
python -m jarvis --text          REM ввод текстом + HUD
python -m jarvis --text --no-ui  REM только консоль
python -m jarvis --no-ui         REM голос без окна
python -m jarvis --no-speak      REM без озвучки
```

## Как пользоваться

1. Запустите ассистента.
2. Дождитесь фразы «Слушаю вас, сэр.»
3. Скажите **«Джарвис»** и сразу команду, либо только «Джарвис» — он подождёт следующую фразу.
4. Примеры:
   - *Джарвис, найди информацию о сосновом брусе*
   - *Джарвис, открой проводник*
   - *Джарвис, открой калькулятор*

## Структура

```
jarvis/
  __main__.py      # точка входа
  listen.py        # микрофон + распознавание
  speak.py         # голос (Edge TTS)
  commands.py      # разбор русских команд
  actions/system.py# Chrome, Проводник, приложения
  ui/hud.py        # окно-интерфейс
```

## Замечания

- Распознавание идёт через Google Speech (нужен интернет). Офлайн можно позже подключить Whisper.
- Голос по умолчанию: `ru-RU-DmitryNeural`. Смена: `set JARVIS_VOICE=ru-RU-SvetlanaNeural`
- Ассистент управляет **вашим** компьютером только по вашим голосовым командам.
