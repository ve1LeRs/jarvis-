# J.A.R.V.I.S. — голосовой ассистент

Голосовой помощник в духе JARVIS из «Железного человека»: слушает **«Джарвис»**, выполняет команды и отвечает голосом.

## Установка как обычной программы

### Вариант A — готовый `JARVIS.exe` (рекомендуется)

На **Windows** в папке проекта:

```bat
build_exe.bat
```

Появится файл **`dist\JARVIS.exe`**. Затем:

```bat
install_exe.bat
```

или один раз: `dist\JARVIS.exe --install-app`

Дальше программа ведёт себя как обычная:
- ярлык на рабочем столе  
- меню «Пуск»  
- автозапуск с Windows  
- без чёрного окна консоли  
- иконка в трее  

Двойной клик по `JARVIS.exe` = запуск в фоне.

### Вариант B — через Python (если exe ещё не собран)

Дважды нажмите **`Установить JARVIS.bat`**.

Удаление ярлыков: `uninstall.bat`.

| «Джарвис, открой проводник / загрузки / документы» | Папки |

| «Джарвис, скриншот» | Снимок экрана в Pictures |
| «Джарвис, посчитай 25 * 4» | Калькулятор |
| «Джарвис, запиши купить молоко» | Заметки (`~/.jarvis`) |
| «Джарвис, через 10 минут напомни про чай» | Напоминания |
| «Джарвис, анекдот / монетка / кубик» | Развлечения |
| «Джарвис, статус» | Система / батарея |

Данные (заметки, история, настройки) хранятся в `%USERPROFILE%\.jarvis\`.

## Spotify

**Работает сразу** (без ключей): Jarvis открывает приложение Spotify и поиск по фразе  
(`spotify:search:…`), затем пытается запустить первый результат.

Для **точного включения трека** и поиска **в вашей медиатеке** задайте переменные окружения  
(приложение на [developer.spotify.com](https://developer.spotify.com/dashboard), redirect URI любой localhost, scope: `user-modify-playback-state user-read-playback-state user-library-read`):

```bat
setx SPOTIFY_CLIENT_ID "your_client_id"
setx SPOTIFY_CLIENT_SECRET "your_client_secret"
setx SPOTIFY_REFRESH_TOKEN "your_refresh_token"
```

Нужен установленный **Spotify для Windows** (или открытие через браузер как запасной вариант).  
Активное устройство Spotify должно быть запущено на ПК, если используете API-воспроизведение.

## Требования

- Windows 10/11  
- Микрофон и динамики  
- Интернет (распознавание речи + голос)  
- Google Chrome (желательно)  

Разрешите доступ к микрофону в параметрах Windows.

## Ручные режимы

```bat
start_jarvis.bat              REM окно + голос
start_jarvis_silent.vbs       REM тихий фон (как автозапуск)
start_jarvis_text.bat         REM команды текстом
python -m jarvis --text       REM отладка
python -m unittest            REM тесты
```

## Структура

```
build_exe.bat           ← собрать JARVIS.exe
install_exe.bat         ← поставить exe как программу
Установить JARVIS.bat   ← вариант без сборки exe (через Python)
jarvis.spec             ← настройки PyInstaller
JARVIS.py               ← точка входа для exe
jarvis/                 ← код ассистента
tests/                  ← unit-тесты команд
```
