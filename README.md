# J.A.R.V.I.S. — голосовой ассистент

Голосовой помощник в духе JARVIS из «Железного человека»: слушает **«Джарвис»**, выполняет команды и отвечает голосом.

## Установка как обычной программы (один раз)

1. Скопируйте папку проекта на Windows-ПК  
2. Дважды нажмите **`Установить JARVIS.bat`**  
3. Готово

Установщик сам:
- поставит зависимости  
- создаст ярлык на рабочем столе  
- добавит пункт в меню «Пуск»  
- включит автозапуск при включении компьютера  
- предложит сразу запустить JARVIS  

После этого JARVIS работает как обычная программа: ярлык → запуск, или сам стартует с Windows.  
Отдельно ничего запускать не нужно.

Удаление: `uninstall.bat` (убирает ярлыки и автозапуск).

> Нужен [Python 3.10+](https://www.python.org/downloads/) с галочкой **Add python.exe to PATH** (только для установки).

### Сделать настоящий `JARVIS.exe` (опционально)

```bat
build_exe.bat
```

Появится `dist\JARVIS.exe` — один файл без консоли, как у обычных программ.  
Его можно копировать и запускать: `JARVIS.exe --install-app`.

## Возможности

| Команда | Что делает |
|--------|------------|
| «Джарвис, найди информацию о сосновом брусе» | Открывает Chrome и ищет в Google |
| «Джарвис, открой проводник» | Открывает Проводник Windows |
| «Джарвис, открой хром» | Запускает Google Chrome |
| «Джарвис, открой ютуб» | Открывает YouTube |
| «Джарвис, открой загрузки» | Папка Downloads |
| «Джарвис, который час» | Говорит текущее время |
| «Джарвис, заблокируй» | Блокирует компьютер |
| «Джарвис, включи автозапуск» | Автозагрузка с Windows |
| «Джарвис, помощь» | Список возможностей |

## Почему раньше было много `.bat`?

Обычные программы из магазина — это уже собранный `.exe` + установщик.  
JARVIS сначала был исходниками на Python (как рецепт, а не готовое блюдо), поэтому шаги были раздельными.  
Теперь **`Установить JARVIS.bat`** делает всё сразу; при желании `build_exe.bat` собирает один `.exe`.

## Требования

- Windows 10/11  
- Микрофон и динамики  
- Интернет (распознавание речи + голос)  
- Google Chrome (желательно)  

Разрешите доступ к микрофону в параметрах Windows.

## Ручные режимы (не обязательны)

```bat
start_jarvis.bat              REM окно + голос
start_jarvis_silent.vbs       REM тихий фон (как автозапуск)
start_jarvis_text.bat         REM команды текстом
python -m jarvis --text       REM отладка
```

## Структура

```
Установить JARVIS.bat   ← главный установщик
uninstall.bat           ← удаление ярлыков
build_exe.bat           ← сборка JARVIS.exe
jarvis/                 ← код ассистента
```
