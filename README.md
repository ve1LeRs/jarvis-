# J.A.R.V.I.S. — голосовой ассистент

Голосовой помощник в духе JARVIS из «Железного человека»: реагирует **только** на **«Джарвис»**, дослушивает фразу до конца и отвечает голосом.

## Быстрый тест без скачивания exe

Клонируй репозиторий **один раз**, дальше только обновляй код:

```bat
Установить JARVIS.bat      REM один раз: Python-окружение
Обновить и тест.bat        REM git pull + сразу тест
```

Или по отдельности:

| Файл | Зачем |
|------|--------|
| `Обновить.bat` | `git pull` + обновить библиотеки |
| `Тест текстом.bat` | команды с клавиатуры, без микрофона и TTS |
| `Тест голосом.bat` | голос + логи в консоли |

Exe нужен только для «как обычная программа». Для проверки фич достаточно Python-режима.

## Установка как обычной программы

### Вариант A — готовый `JARVIS.exe` (когда всё уже ок)

На **Windows** в папке проекта:

```bat
build_exe.bat
```

Появится файл **`dist\JARVIS.exe`**. Затем:

```bat
install_exe.bat
```

или один раз: `dist\JARVIS.exe --install-app`

Дальше программа ведёт себя как обычная:
- ярлык на рабочем столе  
- меню «Пуск»  
- автозапуск с Windows  
- без чёрного окна консоли  
- иконка в трее  

Двойной клик по `JARVIS.exe` = запуск в фоне.

### Вариант B — через Python (если exe ещё не собран)

Дважды нажмите **`Установить JARVIS.bat`**.

Удаление ярлыков: `uninstall.bat`.

## Возможности

| Команда | Что делает |
|--------|------------|
| «Джарвис, найди информацию о сосновом брусе» | Открывает Chrome и ищет в Google |
| «Джарвис, открой проводник» | Открывает Проводник Windows |
| «Джарвис, открой хром» | Запускает Google Chrome |
| «Джарвис, открой ютуб» | Открывает YouTube |
| «Джарвис, открой стим» | Запускает Steam (`C:\Program Files (x86)\Steam\steam.exe`) |
| «Джарвис, открой загрузки» | Папка Downloads |
| «Джарвис, который час» | Говорит текущее время |
| «Джарвис, заблокируй» | Блокирует компьютер |
| «Джарвис, включи автозапуск» | Автозагрузка с Windows |
| «Джарвис, помощь» | Список возможностей |

## Почему раньше было много `.bat`?

Сначала это были исходники Python. Теперь `build_exe.bat` собирает один **`JARVIS.exe`**, а `install_exe.bat` регистрирует его в Windows как обычную программу.

Сборка на GitHub Actions: при пуше в `main` workflow **Build JARVIS.exe** кладёт готовый файл в Artifacts (Actions → последний run → JARVIS-windows).

## Требования

- Windows 10/11  
- Микрофон и динамики  
- Интернет (распознавание речи + голос)  
- Google Chrome (желательно)  

Разрешите доступ к микрофону в параметрах Windows.

## Ручные режимы (не обязательны)

```bat
Обновить и тест.bat           REM удобнее всего при разработке
Тест текстом.bat              REM без микрофона
Тест голосом.bat              REM голос + логи
start_jarvis.bat              REM окно + голос
start_jarvis_silent.vbs       REM тихий фон (как автозапуск)
python -m jarvis --text --no-ui --no-speak
```

## Структура

```
Обновить и тест.bat     ← git pull + тест (без exe)
Тест текстом.bat        ← быстрая проверка команд
Тест голосом.bat        ← проверка микрофона
Установить JARVIS.bat   ← один раз через Python
build_exe.bat           ← собрать JARVIS.exe
install_exe.bat         ← поставить exe как программу
jarvis.spec             ← настройки PyInstaller
JARVIS.py               ← точка входа для exe
jarvis/                 ← код ассистента
```
