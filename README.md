# J.A.R.V.I.S. — голосовой ассистент

Голосовой помощник в духе JARVIS из «Железного человека»: слушает **«Джарвис»**, выполняет команды и отвечает голосом.

## Удобный цикл теста (без перекачки zip каждый раз)

**Один раз** клонируете репозиторий (не скачивайте ZIP при каждом обновлении):

```bat
git clone https://github.com/ve1LeRs/jarvis-.git
cd jarvis-
Установить JARVIS.bat
```

**Дальше только обновляете код:**

| Файл | Зачем |
|------|--------|
| `update.bat` | `git pull` + доустановка зависимостей |
| `dev.bat` | быстрый тест командами **без** микрофона и TTS |
| `start_jarvis_text.bat` | текстовый режим с голосом |
| `start_jarvis.bat` | обычный голос + HUD |
| `run_tests.bat` | unit-тесты |
| `switch_branch.bat` | переключить ветку PR |

Голосом или в `dev.bat`: «обнови джарвис», «версия».

Переменная `JARVIS_UPDATE_BRANCH` задаёт ветку для `update.bat` (по умолчанию текущая).

## Установка как обычной программы

### Вариант A — готовый `JARVIS.exe`

Скачайте [JARVIS.exe из Releases](https://github.com/ve1LeRs/jarvis-/releases/latest) и запустите `JARVIS.exe --install-app` (или соберите сами: `build_exe.bat`, затем `install_exe.bat`). Дальше exe обновляется сам — см. «Автообновление».

Для ежедневной разработки удобнее **вариант B (Python + update.bat)** — exe пересобирать не нужно.

### Вариант B — через Python (рекомендуется для тестов)

Дважды нажмите **`Установить JARVIS.bat`** (`.venv` переиспользуется, не создаётся заново).

Удаление ярлыков: `uninstall.bat`.

Данные (заметки, история, настройки) хранятся в `%USERPROFILE%\.jarvis\`.

**Память о вас.** «Запомни, что …» сохраняет факт в `%USERPROFILE%\.jarvis\facts.json` (обычное «запомни …» без «что» — по-прежнему заметка). На личные вопросы («как меня зовут», «когда мой день рождения») Джарвис отвечает из памяти, а при ответах через Ollama факты подставляются в подсказку модели.

**Озвучка по предложениям.** Длинный ответ режется на куски: первый — короткий, чтобы голос зазвучал сразу, следующие синтезируются, пока играет текущий.

## Ваш стек программ

Jarvis заточен под ежедневный набор: **Discord, Chrome, Spotify, CS2, PUBG, Cursor, Word**.

| Режим / команда | Что поднимает |
|-----------------|---------------|
| `рабочий режим` | Cursor + Chrome + Word |
| `режим кода` | Cursor + GitHub в Chrome |
| `чилл режим` | Spotify + Discord + YouTube |
| `игровой режим кс` / `го в пабг` | Discord + CS2/PUBG, Spotify на паузе |
| `матч кс` / `матч пабг` | + Discord deafen; `выйди из игры` откатывает |
| `мют` / `деф` / `зайди в войс …` | хоткеи Discord + Quick Switcher |

Игры запускаются через Steam (`steam://rungameid/730` и `578080`).  
При необходимости ID можно переопределить: `JARVIS_CS2_APP_ID`, `JARVIS_PUBG_APP_ID`.

## Spotify

**Работает сразу** (без ключей): Jarvis открывает приложение Spotify и поиск по фразе  
(`spotify:search:…`), затем пытается запустить первый результат.

Для **точного включения трека**, плейлистов и очереди удобнее голосовой мастер:

1. Создайте приложение на [developer.spotify.com](https://developer.spotify.com/dashboard)  
2. Redirect URI: `http://127.0.0.1:8732/callback`  
3. Скажите: «сохрани спотифай ключи CLIENT_ID CLIENT_SECRET»  
4. Затем: «войти в спотифай» / «настрой спотифай» — откроется браузер, токен сохранится в `%USERPROFILE%\.jarvis\spotify.json`

Либо по-старому через переменные окружения (`SPOTIFY_CLIENT_ID` / `SECRET` / `REFRESH_TOKEN`).

Нужен установленный **Spotify для Windows** (или открытие через браузер как запасной вариант).  
Активное устройство Spotify должно быть запущено на ПК, если используете API-воспроизведение.

## Календарь, плагины, LLM, Vision, PTT

- **Календарь:** публичная ICS-ссылка Google/Outlook → «добавь календарь https://…», «календарь», «что сегодня»
- **Плагины:** файлы `*.py` в `%USERPROFILE%\.jarvis\plugins\` (см. README там же)
- **Локальная модель:** [Ollama](https://ollama.com) на `127.0.0.1:11434`, `JARVIS_OLLAMA_MODEL` (по умолчанию `llama3.2`)
- **Vision:** `ollama pull llava` (или `JARVIS_VISION_MODEL`), затем «опиши экран» / «что на экране»
- **Push-to-talk:** Ctrl+Alt+J (без «Джарвис»); клавиша через `JARVIS_PTT_VK`
- **Проактивность:** утренний брифинг, напоминания по делам, «вы давно в игре»

## Мост с телефона (Telegram / WhatsApp)

### Telegram
1. Создайте бота у [@BotFather](https://t.me/BotFather)  
2. «сохрани телеграм токен 123456:ABC…» (или `TELEGRAM_BOT_TOKEN`)  
3. Напишите боту любое сообщение, узнайте chat id и при желании: «разреши телеграм чат 123456789»  
4. «включи телеграм мост» (или «включи мост»)

### HTTP / WhatsApp
- Локальный сервер: `http://127.0.0.1:8765` (`JARVIS_BRIDGE_PORT`)
- Простые команды: `POST /command` с телом `{"text":"открой дискорд","secret":"..."}`  
  Секрет: «секрет моста mysecret» или `JARVIS_BRIDGE_SECRET`
- WhatsApp Cloud API: «сохрани ватсап TOKEN PHONE_NUMBER_ID [verify]», webhook `…/whatsapp`  
  (нужен публичный туннель, например cloudflared/ngrok)
- Любой WhatsApp-шлюз может слать `POST /whatsapp` `{"text":"…","from":"7900…","secret":"…"}`

## Автообновление

Сборка на GitHub Actions: при пуше в `main` workflow **Build JARVIS.exe** публикует готовый файл в [Releases](https://github.com/ve1LeRs/jarvis-/releases/latest) с тегом `build-<номер>`.

Скачать `JARVIS.exe` нужно **один раз**. (В сборках 3–6 подмена файла зависала: JARVIS закрывался и не возвращался. Если у вас одна из них — один раз скачайте свежий exe вручную, дальше обновления идут сами.) Дальше программа сама проверяет обновления при запуске и каждые 6 часов: если в Releases появилась более новая сборка, она скачивается, подменяет `JARVIS.exe` и JARVIS перезапускается. «Обнови джарвис» проверяет сразу.

Текущая версия видна в меню и подсказке иконки в трее, в заголовке окна и по команде «Джарвис, версия» (`сборка N` для exe, `dev <коммит>` из исходников). После автообновления трей один раз показывает уведомление «JARVIS обновлён: сборка N → M». Пункт трея «Проверить обновления» проверяет сразу.

Если JARVIS запущен из исходников (через Python), в фоне выполняется `git pull --ff-only` текущей ветки и перезапуск; `update.bat` / «обнови джарвис» дополнительно обновляют зависимости.

Отключить: запуск с `--no-update` или переменная окружения `JARVIS_NO_UPDATE=1` (`dev.bat` не обновляется сам).

## Требования

- Windows 10/11  
- Микрофон и динамики  
- Интернет (распознавание речи + голос)  
- Google Chrome (желательно)  

Разрешите доступ к микрофону в параметрах Windows.

## Ручные режимы

```bat
start_jarvis.bat              REM окно + голос
start_jarvis_silent.vbs       REM тихий фон (как автозапуск)
start_jarvis_text.bat         REM команды текстом
python -m jarvis --overlay    REM компактный оверлей поверх окон
python -m jarvis --text       REM отладка
python -m unittest            REM тесты
```

Данные макросов/дел: `%USERPROFILE%\.jarvis\` (`macros.json`, `todos.json`).  
OCR «что на экране» лучше работает с установленным `tesseract` (rus+eng).

## Структура

```
build_exe.bat           ← собрать JARVIS.exe
install_exe.bat         ← поставить exe как программу
Установить JARVIS.bat   ← вариант без сборки exe (через Python)
jarvis.spec             ← настройки PyInstaller
JARVIS.py               ← точка входа для exe
jarvis/                 ← код ассистента
tests/                  ← unit-тесты команд
```
